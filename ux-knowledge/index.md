## テーマ別インデックス

### T1: 人間理解・心理・バイアス
> 認知の仕組み、動機、感情。組織・チーム・ユーザー設計の基盤。

- **確証バイアスと第一印象の固定化** — 悪い第一印象は確証バイアスでブランド評価を下げ続ける `S07`
- **非注意性盲目（Inattentional Blindness）** — 注意を向けていないものは存在しないも同然 `S07`
- **損失回避（プロスペクト理論）** — 「得る」より「失う」恐怖の方が人を動かす。車の整備「このままだとボロボロ」事例 `S06`
- **二分法の誤謬** — 「何を飲みますか？」と聞かれると、飲みたくなくても選んでしまう。リサーチの設問設計に直結 `S07`
- **ディセプティブデザインの禁忌** — 心理学をユーザー誘導に使うのは逆効果。ユーザーに良いデザインが結果的に売上につながる `S07`
- **ユーザー心理と「間（テンポ）」** — 便利な機能でも会話テンポの心理的ストレスで使われなくなる。翻訳アプリ事例 `S07`
- **Unknown Knowns** — 「気づいていないが、対処できること」の発見。超一流はこれを見抜く `S07`
- **脱構築（デリダ）** — 「シンプル/複雑」「直感的/非直感的」などの二項対立を問い直す。前提のバイアスを可視化する4ステップ `S05`

### T2: ユーザーリサーチ・インサイト発掘
> 本音を引き出す。リサーチの限界を超える。

- **意味のないリサーチの罠** — 競合調査のみ・言葉を鵜呑みにする・目的なしに聞く。「誰に」「何を聞くか」を先に決める `S07`
- **自己申告バイアス** — ユーザーは「欲しいもの」を正確に言語化できない。アンケートと実態の乖離に注意 `S03` `S07`
- **シミュレーションモデリング（ABM）** — 数千の仮想ユーザーを動かし「創発」を観察する。「点」の検証では見えない「面」の問題を捉える。デジタルツイン的発想。行動科学・心理学・社会学の知見がそのままエージェントルール設定に使える `S03`
  - 5つの問いに答える: 仮説のリアリティチェック、自己申告の検証、スケーリングの転換点、戦略的優先順位、コールドスタート
- **本音の発掘** — 表面的属性でなく「口癖→思考→本音」という経路で掘り下げる。「分かったふりの限界から解放されたい」等 `S07`

### T3: AI×UX設計
> AIの本質を理解した上で設計する。

- **AIは確率で動く** — 「魔法の箱」ではなく「次に来る言葉として最もらしいものを選ぶ仕組み」。これを知らずに設計すると失敗する `S01`
- **AIプロジェクト85%失敗** — 失敗の典型: 「何でもできる」狙い、ハルシネーション・バイアスリスク未考慮 `S01`
- **バリューマトリクス** — 真陽性/偽陽性/偽陰性/真陰性で起こりうる事象を定量評価。鍋の吹きこぼれ検知AI事例。AIに「100%の精度」は保証できないため、利益とコストを事前計算することが必須 `S01`
- **AIの6つのコア能力** — 検出・識別・推定・予測・生成・行動。要件をこの能力に当てはめてから設計する `S02`
- **AIを中心に据えない設計** — 「自然な会話のインターフェース」と「従来の高速なシステム」の間にAIを配置する。ユーザーの意図解釈にのみAIを使い、データ処理は非AIで `S02`
- **チャットUIの限界** — ユーザーは長文・遅レスポンス・毎回コンテキスト説明に疲弊。チャットだけがAIのUIではない `S02`
- **「AI搭載」表記の逆効果** — 明記するとコンバージョンが下がる事例あり。キラキラアイコンも非IT職には通じない `S02`
- **Quiet AI（静かなAI）** — 前面に押し出さず既存ワークフローに溶け込ませる。Dovetailの文字起こし・ハイライト自動提案事例 `S02`
- **AIデザインの6領域** — 入力/出力/洗練ジャーニー/アクセシビリティ/オーケストレーション。洗練ジャーニーが最もフラストレーションが溜まりやすい `S02`
- **AIユースケース別の構築方法** — 機械学習/AIワークフロー/エージェント/SLMでやりたいことによって構築が全く異なる。混同が組織のAI活用失敗の原因 `S04`

### T4: 組織・チーム・対話設計
> 人が動く場の設計。組織にそのまま転用できる知見。

- **フィードバックの本質** — NPSやレビューは「本物のフィードバック」ではない。本物は「真の問いへの実体験に基づく答え」。5つの属性: 1対1、弱さを見せる覚悟、具体性、行動に移せる、信頼の構築。「信頼は徒歩でやってきて馬で去る」 `S05`
- **問いかけ型フィードバック** — 「どう思った？」という問いかけが相手の気づきを促す。心理的安全性が前提 `S05`
- **レビューをジャムセッションへ** — 完成品だけ持ち込む「タレントショー」から、初期段階から全員で音を合わせる「ジャムセッション」へ。Booking.comの6原則 `S03`
- **「引き出す場」と「語り合う場」の使い分け** — 前者は相手ドメインに特化した問いをセット（CSなら「顧客の混乱を招かないか」）。後者は結論を急がない余白を作る `S03`
- **組織のAI活用成熟モデル** — Stage1（バラバラ）→ Stage2（知識は揃うが戦略なし）→ Stage3（戦略と共通認識）。多くの組織はまだStage1 `S04`
- **アライメントの幻想** — 言葉による合意は脆い。「素晴らしいリンゴ」で全員の頭のリンゴは違う。ナプキンの粗い絵1枚が何週間もの戦略文書より合意を形成できる `S04`
- **粗い絵 vs きれいな絵** — 粗い絵は「まだ合意を取りに行く」段階に有効。AIで高品質な絵が瞬時に作れる今こそ、プロセスのどこで使うかの戦略的設計が必要 `S04`
- **PdMは「場の設計者」** — 適切な「問い」と「環境」をセットし、知識を経験に変える場をプロデュースすることがPdMの価値 `S03`

### T5: コミュニケーション・説得・伝達
> 人を動かす語り方。

- **事実→物語→ドラマの3段階** — レベル1「ニュース（事実）」→レベル2「物語（背景と行動）」→レベル3「ドラマ（感情と利害）」。経営やチームに行動を促すには「ドラマ」まで届ける必要がある `S06`
- **行動しないことのコスト** — 「このまま何もしないとどうなるか」が最強の説得材料。世界銀行ザンビア事例: 膨大なデータより「一人の医療従事者の苦悩」で会場の空気が一変 `S06`
- **ユーザーの顔と感情を見せる** — 「顔が見えないと人を殺すことが簡単になる」。メタファーで共感を引き出す `S06`
- **マイクロコピー** — 「お試し」より「使う」。会話体ライティングがCTAの基礎 `S07`
- **ビジュアル化による学習定着** — スケッチ等でビジュアル化すると「理解促進・関連付け・俯瞰による新視点」が得られる `S07`

### T6: プロダクト開発・意思決定
> 何を作り、何を作らないか。

- **MVPの本質** — 「ユーザーの最も重要なペインを解決する機能」。初歩的な機能ではない。ミスを防ぐUI設計も含めてMVP `S07`
- **Less but Better** — 効果の薄い機能は技術的負債。生存指標を設けて「やめる」決断が重要。善（70点）が最善の敵になる `S07`
- **バリュープロポジションキャンバス（VPC）の正しい使い方** — 企業都合でサービスを当てはめるのではなく、顧客のジョブ・ペイン・ゲインから価値提案を描く `S07`
- **ジョブ理論** — ユーザーは「記事を読みたい」のではなく「習慣化したい」。ドリルと穴の理論。本当のジョブを外さない `S07`
- **ヒックの法則** — 選択肢が多いと選べない。情報設計で絞り込みが求められる `S07`
- **イベントストーミング** — ゴール（ビジネス目標）から逆算して「ユーザーが〜した（過去形）」で体験ステップを書き出す。右から左への思考 `S02`
- **AI機能の優先順位付け** — 緊急性・価値/インパクト・実装期間の3軸で評価。ドットボーティングはAIプロジェクトに向かない（目立つ意見が勝つ） `S02`
- **コンテンツインベントリの正しい使い方** — 在庫管理ではなく「誰の、どの本音に刺さる情報を届けるか」の設計ガイド `S07`

### T7: PdM・自己変革・キャリア
> 高橋自身のPdMとしての視点・内省。

- **バイブコーディング（Vibe Coding）の本質** — 完璧なコードでなく「曖昧さを形にすること」。完璧な仕様書を作ってから共有するPMから、未完成のアイデアを議論に持ち込むPMへ `S06`
- **「完璧を目指す」の罠** — 完璧な仕様書は議論の余地がなく「了解です」で終わる。準備の時間がチームと考える時間を奪う `S06`
- **AIにできないこと** — 「思いつく・行動を始める」ことは人間にしかできない。ふわっとした違和感・言語化できない課題を見過ごさない `S06`
- **志の重要性** — 高い目標（志）は困難への耐性を作り、目先の誘惑から身を守る精神的防壁 `S07`
- **強みとキャリア** — 給料だけでなく「自分の強み」と「なりたい自分（志）」を軸に描く `S07`
