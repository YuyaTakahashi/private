# 第五章　上司といい関係を築く ── まとめ（機構中心版）

> マイケル・ワトキンズ『最初の90日』／疑問・感想は `読書ノート.md` に蓄積する。
> 構成方針：「関係を築け」という態度論ではなく、関係を仕組みに置き換えるための道具を主役に再構成した。

## この章の主張（ひとことで）

直属の上司は評価基準・予算・人材・社内での評判をすべて握っており、ブレークイーブン・ポイント到達の速さを左右する。この関係を相性や運に任せず、**議題・順序・書面・チェックポイントという仕組みに置き換える**。多くの新任リーダーは始めから諦めて相手のペースでゲームを進めて消耗する。先手で交渉し、自分のフィールドに持ち込む。

---

## 道具箱（この章の機構）

### 道具1：五つの対話テーマと「順序」（この章の中核）

- **目的**：上司との対話を漫然と行わず、合意すべき議題を5つに分け、依存関係の順に積む。
- **5テーマと順序**：
  1. **現状認識**：上司は今を〈四つの状況〉のどれと見ているか。なぜそうなったか。**すべての土台**。ここが食い違ったままだと援護射撃が得られない。
  2. **期待**：何をもって「合格」か。いつ・どう測定されるか。短期・中期に何を期待されているか。
  3. **スタイル**：連絡手段・頻度・必ず相談すべき案件・自由裁量の範囲。
  4. **経営資源**：①〜③で合意してから交渉する（土台なしの「おねだり」は通らない）。
  5. **能力開発**：関係ができてから。この仕事のキャリア上の位置づけ、磨くべき能力、率直なフィードバック。
- **順序のルール**：着任直後＝①②③ → 状況が見えてきたら④ → 関係ができてきたら⑤。資源や期待の交渉から入るのは、土台（現状認識の一致）がないので失敗する。
- **運用**：1回のミーティングで複数テーマでも、1テーマを何度かに分けてもよい。ミーティング前にシナリオを練る。

### 道具2：90日プランの契約化

- **目的**：上司との合意を口約束でなく「契約」にする。
- **手順**：着任2〜3週間で、優先順位・最終目標・中間目標だけの簡単なプランを**必ず紙に書く** → 上司に見せて了解を取る → **90日プランは上司との契約と認識する**。
- **チェックポイント構造**：90日を30日×3に区切る。最初の30日＝学習と信頼の獲得（学習科目と週次目標・評価基準を決める）→ 30日目：現状認識と期待を相互確認、次の30日の計画に了解 → 60日目：進捗確認と次の計画の同意 → 90日目：資源・戦略・チーム評価を話し合う。

### 道具3：期限の交渉（マイケルの初手）

- **目的**：いきなり成果を急かされる展開を防ぎ、診断の時間を確保する。
- **型**：着任時に先手で構造を提案する。「移行期間を90日と考えている。最初の30日で重要な問題を把握し、現状分析を報告する。その時点で次の60日の目標と計画を話し合いたい」→ 了解を取る。
- **効果**：恐れられた上司ボーガン相手でも、マイケルはこれで時間という資源を確保し、相手のペースに飲まれなかった。

### 道具4：期待の操作

- **目的**：「期待に応える」のではなく、期待そのものを交渉・誘導の対象にする。
- **ルール群**：
  - **組織で勝つには期待は低い方が好ましい**。非現実的な期待は交渉して下げる。
  - **上司を教育する**：見当外れの思い込みには、さりげなく情報をインプットして見方を変える（上司自身が問題の張本人なら特に配慮）。
  - **大風呂敷を広げない**：小さな約束、大きな成果。約束以上なら喜ばれ、惜敗でも負けは負け。
  - **念押し、確認、再確認**：目標と期待の誤解は何度でも質問して潰す。「上司と部下に食い違いがあったら、勝つのは必ず上司」。
  - **悪い報せは即第一報**：他ルートから上司の耳に入るのが最悪（不意打ちの禁止）。問題には解決案を添える。

### 道具5：状況別サポート要求リスト（表5-1）

- **目的**：上司への依頼を「予算・人」の一般論でなく、〈四つの状況〉に応じて特定する。
- **対応表**：
  - **離陸**：資源をすぐ入手できる支援／明快で測定可能な目標／戦術上の指示／逸脱への注意。
  - **方向転換**：（離陸＋）人事の苦渋の決断を支える／職場のイメージ改善／根本改革の後押し。
  - **針路修正**：（離陸＋）**改革の必要性を訴える援護射撃**。理想は上司が共に先頭に立ち、後ろ向きな空気を一掃すること（特に社外登用の場合に必須）。
  - **高度維持**：現状維持か針路修正かを見きわめる目／重大な失敗を防ぐ守り／新展開への後押し。
- **共通原則**：仕事をするのはあくまで自分。上司にしてもらうのは、指示・サポート・環境整備。

### 道具6：資源交渉の型

- **目的**：資源の要求を通りやすくする。
- **手順**：目標達成に必要なものをハード（予算・人材・技術）／ソフト（援護射撃等）両面で洗い出す → 手札を確認し「これだけはほしい」を絞る → **成果と連動させて要求する**（「7%増収なら予算◯◯、10%なら◯◯」）→ 早めに手の内をさらし、折に触れて交渉する。
- **交渉の3ヒント**：相手の関心事・優先順位をわきまえる／双方にメリットのある提案をする／結果に結びつける。
- **注意**：方向転換・針路修正では要求が大きくなり、通らないと頓挫するリスクも大きい。データを揃え、緊急性を明確にし、援護してくれる人を探したうえで、くよくよして手遅れになるより強行突破。

### 道具7：タブー探知と観測気球

- **目的**：上司の「これだけは譲れない」（立ち上げた製品、お気に入りの部下、仕事の流儀）を地雷を踏む前に知る。
- **手順**：上司のキャリアを調べる／上司をよく知る人と話す／表情・声・身振りに注意する／確信が持てなければ**観測気球を上げて反応を慎重にうかがう**。

### 道具8：特殊ケースの処理

- **複数の上司**：成功/失敗の定義の違いを見きわめる → 強い権限の側にまず従い、後でバランスを取り戻す → 調整不能なら上司同士で話し合ってもらう（板挟みを自分で抱えない）。
- **遠隔の上司**：こまめな連絡＋**評価基準の明文化**（横道に入り込むのを防ぐ）。
- **スタイル対立**：放置すると無能扱いか挑戦的と取られる。「やり方でなく目標」に話を集中し、結果で評価してほしいと誠実に伝える。上司が信頼する人に切り出し方を相談するのも手。一度に全部解決しようとせず、1つずつ。

### 道具9：移行期の黄金律（部下への展開）

- **目的**：この章の道具一式を、そのまま自分と部下の関係に転用する。
- **手順**：自分が上司にしてほしいことをリスト化 → 自分が部下にしてあげていることをリスト化 → 突き合わせる。「してもらう」ばかりなら問題。5つの対話テーマを部下一人ひとりに適用する。部下が早くエンジン全開になるほど自分の目標も達成しやすくなる。

## 心構え系の記述（流し読みでよい部分）

- 「上司とうまくやるのは部下の仕事」「関係構築は100%自分の責任」「殻に閉じこもるな」「上司を変えようと思うな（癖にはこちらが合わせる）」「前任者の悪口を言うな」「些末な報告をするな」→ 単体では態度論。実体は道具1〜8を「自分から起動せよ」という起動条件として読む。
- 悪い上司からも学べる（欠点を棚卸しして我が振りを直す）。

## 事例：マイケル・チェン（道具の実演として読む）

「結果を出せない部下を斬り捨てる」と恐れられる上司ボーガンの下へ。マイケルの動きを道具に分解すると：着任時に期限の交渉で90日構造を提案（道具3）→ こまめな報告で不意打ちを排除（道具4）→ 3週間後、初期の成果報告とセットで人員増強を要求（道具6＝成果と連動した資源交渉）→ 準備で鋭い質問に渡り合い、約束を守り続ける（道具4＝小さな約束大きな成果）→ 1年後「やり方でなく結果で評価してほしい」と直言（道具8＝スタイル対立の処理）。人徳ではなく手続きの積み重ねで関係を構築した。
