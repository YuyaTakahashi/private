# 第二章　謙虚に効率よく学習する ── まとめ

> マイケル・ワトキンズ『最初の90日』／疑問・感想は `読書ノート.md` に蓄積する。

## この章の主張（ひとことで）

着任直後にすべきは「行動」ではなく「学習」である。ただし手当たり次第に聞いて回るのではなく、**学習を投資ととらえ、何を・誰から・どう学ぶかを計画的に決めて効率よく学ぶ**。製品や技術だけでなく、組織文化や人間関係も学習の対象に含める。

## 失敗事例：クリス・バグリー

経営不振の家電メーカー、ホワイト・グッズの最大工場のジェネラル・マネジャーに転じた、製造畑の優秀な男。着任前の視察で「お粗末な実態」を見て即断し、「シグマのやり方で根本から立て直す」と宣言。辣腕コンサルを雇い、現場を「前世紀の遺物」「低能ぞろい」と断じてチーム生産方式を導入した。だが生産性も品質も悪化し、士気は下がる一方。3カ月後、上司に「呼んだのは工場をよくするためで、ぶちこわすためじゃない。経緯を知るのにどれだけ時間をかけたのか。まず話を聞いてみたらどうだ」と諭される。部下と徹底的に話して初めて、限られた予算でいかに工夫してきたかを知り、組織再編を撤回した。

クリスの最大の過ち＝**新しい職場を理解しようとせず独断的な思い込みで動いたこと**。ある環境で成功したやり方が、別の環境でも通用するとは限らない。

## 2つの症候群

- **学習拒否症候群**：「現在の状況に立ち至ったのはなぜか」を聞かないまま、築き上げられたものを壊そうとする。
- **行動強迫症**：「何かしなければ」という強迫観念で焦って動く。忙しくて学習時間が取れないときに陥りやすい。準備不足のまま動くと判断ミスを重ね、部下の不信を招き、重要な報告が上がらなくなる悪循環に入る。

## 学習は投資である

時間とエネルギーが元手、意思決定や行動に役立つ知識がリターン。大量の情報から意味あるものを効率的にふるい分け、何を集中的に学ぶかを決める。クリスの学習態度は効果的でも効率的でもなかった。

## 学習プランのサイクル

**情報収集 → 分析 → 重要情報の抽出 → 仮説の構築 → 仮説の検証 → 理解の深化**

理想は正式着任の前に「学習科目（何を学ぶか）」を決め、その後も定期的に見直すこと。学習は最初は疑問だらけでよく、学ぶにつれて仮説を立て・肉付けし・検証できるようになる。

着眼は**過去・現在・未来**の3軸。
- 過去：業績はどうだったか、好調／不振の原因は何か、これまでの改革とその結果は。
- 現在：公表されたビジョン・戦略は実行されているか、誰が有能・信用でき・影響力を持つか、重要プロセスは妥当な水準か、潜在的な火種・タブーは何か、どこで早期の勝利を出せそうか。
- 未来：今後1年で最も困難な課題はどこか、未活用の有望な機会はどれか、改革の最大の障害は何か、文化のうち残すべきもの・変えるべきものは何か。

## 知識・情報源をみきわめる

ハードなデータ（財務・事業報告、意識調査、業界誌）だけでなく、**ソフトな情報（戦略・技術力・組織文化・人間関係）**を見落とさない。ソフトな情報を知る唯一の方法は、詳しい人にじかに会って聞くこと。社内外の両方に耳を傾ける。

- 社外：顧客／販売店／サプライヤー／社外アナリスト。
- 社内：研究開発・製造・サービス現場／営業・資材調達／専門職（財務・法務・人事）／調整役（裏の人脈や陰の実力者を知る）／古参社員（過去の事情や政治的背景）。

## 学習方法を考える（計画的に臨む）

手当たり次第のヒアリングは非効率で、最初／最後の人の印象に左右されやすい。だから**面談のフォーマットを決めて同じ質問をする**。各人の答えを同じ土俵で比較でき、意見の一致・不一致や、誰が率直かも分かる。

直属の部下に一人ずつ聞く「水平断面」の5つの質問：
1. 現在・近い将来に直面する最大の課題は何か。
2. なぜその課題に直面しているのか。
3. 業績改善につながる未活用の機会はあるか。
4. その機会を生かすには組織のどこを変える必要があるか。
5. もし君が私だったら、何に力を入れるか。

全員に同じ質問をすれば多数派も少数意見も汲め、声の大きい人への偏りも避けられる。答え方を観察すれば、チームの権力関係や各人の姿勢（率直か／責任を認めるか／視野の広さ）も見える。一通り聞いたらチーム・ミーティングで結果を共有する。

その他の学習手法（表2-1）：社員の意識・満足度調査、面談（水平・垂直）、フォーカス・グループ、意思決定分析、プロセス分析、工場視察・顧客訪問、パイロット・プロジェクト。地位や状況に応じて組み合わせる。GEの「新任リーダー導入プロセス」のように、ファシリテーターを介して匿名で部下の声を集める仕組みも紹介される。

## 組織文化を学ぶ

文化はズームレンズのように、組織 → 職業 → 地域の3レベルで捉える。
- 組織文化：人間関係、仕事への姿勢、日常の習慣に表れる。
- 職業文化：職種ごとの固有の雰囲気（例：エンジニアと事務職）。
- 地域文化：国・地域による違い。

各レベルの適応難易度を点数化し、3項目の合計が高ければ相当なカルチャー・ショックを覚悟する。そのうえで、自分が文化に**順応するのか／文化を修正するのか**を決める。判断の起点は「文化のどの面が業績改善にプラスで、どの面がマイナスか」を理解することにある。

## 章末チェックリスト

2. 何を学ぶ必要があるか。質問リストや「なぜ今こうなったか」の仮説を作る。
3. 的確な答えをくれそうな人は誰か。
4. 学習効率を高めるにはどうするか。
5. 質問の答えが見えたら学習プランを立てる。
