# 第六章　組織をデザインする ── まとめ

> マイケル・ワトキンズ『最初の90日』／疑問・感想は `読書ノート.md` に蓄積する。
> 構成：本書の流れ（全体像 → 4S+1C の各要素 → 設計手順 → 落とし穴）に沿って解説し、要点ごとに使える道具を併記する。

## この章の位置づけ（全体像）

地位が上がるほど、リーダーの仕事は「自分が動いて成果を出す」ことから「**部下が成果を出しやすい組織を設計する**」ことに移る。著者は「リーダーはアーキテクト（建築家）たれ」と言う。どれほど有能でも、屋台骨が歪んだ組織では成果は出ず、毎日あちこちの綻びを繕う徒労に終わる。

ところが管理職で組織設計を学んだ人はほとんどいない。新人時代は組織全体を見る機会がなく、「なぜ上はこの非効率を放置するのか」と文句を言っていた人が、いつの間にか同じ側に回る。だから昇進したら意識的に学ぶ必要がある。

この章のゴールは、組織を**〈四つのSと一つのC〉**に分解して診断し、**要素間の噛み合わせ（整合）の崩れ＝不協和音**を見つけて直すこと。90日でできるのは粗い診断と「最悪の部分」への着手までで十分。なお、組織を変える権限がなくても読む価値がある——「業績低迷の原因は組織体制にある」と上司を説得する道具になるからで、事例のハナ自身がそれを実演している。

---

## 〈四つのSと一つのC〉とは

組織が目標を達成するには、次の5要素が噛み合う必要がある（図6-1）。

- **戦略（Strategy）**：目標達成までのグランドデザイン（何をして何をしないか）。
- **組織構造（Structure）**：人材配置と業務分担。
- **システム（System）**：業務プロセスの集合体。
- **スキル（Skill）**：個人やチームの能力。
- **文化（Culture）**：価値観・規範・信念。4Sすべてを包み込む。

中心に戦略があり、構造・システム・スキルと相互に結びつく。戦略を変えれば他も変わる。そして全体を文化が包む。

### 最重要の発想：単独採点でなく「噛み合わせ」を診る

各要素を一個ずつ「いい戦略か」「いい人材か」と採点しても足りない。**各要素が単独で立派でも、つなぎ目がずれていれば組織は回らない**。問題は要素と要素の間に出る。

- 例（ハナの会社）：人材は優秀、報酬制度（個人の成果に報いる）もそれ自体は真っ当＝単独なら合格。だが戦略は「部門が協力して顧客に一体的サービスを」なのに、報酬は「個人成績で報いる＝協力の動機がない」方向を向き、戦略と制度が逆向き。結果、優秀な人材が顧客を奪い合った。
- 比喩：高級ギアと高級チェーンを別々に買っても規格が合わなければ走らない。
- だから問いは常にペアで立てる：「戦略と制度は同じ方向か」「戦略とスキルは噛み合うか」。

**不協和音の典型パターン**：戦略×スキル（新商品を出す戦略なのに実験を効率化する技術がない）／システム×戦略（新規顧客戦略なのに顧客情報を蓄積・分析する仕組みがない）／構造×システム（製品別チームなのに他チームの知識を使う仕組みがない）。

---

## 設計の手順（順番を間違えない）

1. **戦略を立てる**。全社目標の中での自部署の位置づけ（割り当てられた役割）を確かめ、自分の業績目標とつながっているか点検してから立てる。自部署だけ見て作ると全社とズレる。※位置づけ・業績目標は一人で決めず、上司との対話（第五章）で確かめる。
2. **構造・システム・スキルで戦略を支えられるか吟味する**。支えられないならどう対処するか。
3. **新戦略の導入時期と方法を決める**（無理のない期限）。
4. **構造・システム・スキルは同時に変える**。三者は密接に結びつき、一つだけ取り出せない。
5. **学習し続ける**。設計は一回で終わらず円環。変えた結果を観察し、改善余地を次の設計に戻す（具体的な学習法は第二章の学習サイクルを組織に対して回す）。

原理：戦略を決めずに構造をいじるのは非効率。能力開発も目標・戦略・構造が定まってから。

## 第一のS：戦略

戦略とは「何をすべきで何をすべきでないかを決めるもの」。

**中身を組み立てる材料＝4つのC**：顧客（大切にする顧客は誰か、撤退・参入すべきセグメントは）／資金（投資が有望な分野は、資源は確保されているか）／能力（何が得意・不得意か、これから要る能力は自前で育つか）／重点分野（資源をいつどこに投入するか、継続・撤退するものは）。

**できた戦略を検査する3レンズ**：
- **整合性**：構成要素（市場・製品・技術・実行計画・目標）が矛盾なく調和しているか。
- **妥当性**：今後2〜3年のニーズと全社戦略に照らして適切か。手法＝裏付けをとる／SWOT分析／立案プロセスの検証（短時間で作られた→波及効果が未検討／会議を重ねた→最大公約数的妥協の恐れ）。
- **実行状況**：**部下の説明より行動に注目**。評価基準は戦略とリンクし日々の意思決定に生きているか、管理職の行動は戦略と矛盾していないか。

> 道具メモ：4C＝戦略を「作る/分解する」材料表。3レンズ＝できた戦略を「採点する」評価シート。順番は4Cで把握→3レンズで検査。本書は両者の記述が一部重複している。

**戦略の変更**：「うまくやっている」と信じる部下に変更を説得するのは最難関。質問で揺さぶる（「実現したら副作用はないか」「市場拡大は本当に望みか」「もっと現実的な目標を別に置いては」）。妥当だが進みが鈍いだけなら、当面は微調整で様子見し、実態把握と援護射撃を得てから大幅変更へ。

## 第二のS：組織構造（※今回の関心ポイント）

戦略変更の必要が見えたら、それを支えられるよう構造を見直す。組織構造は次の**4要素**から成る。

### 組織構造の4要素

1. **事業単位（編成の切り口）**：組織を何で割っているか。職能別（営業・開発・製造…）／製品別（製品ライン別）／地域別（エリア別）のどれか。同じ人員でも、どの切り口で束ねるかで強みも弱みも変わる。
2. **意思決定権**：どの問題を誰が決めるか。意思決定はどんなプロセスで行われるか（誰の承認が要るか、どこで決まるか）。
3. **実績評価・報酬制度**：実績をどう測り、どう報いるか。何を評価するかで人の行動が決まる（評価される行動が増える）。
4. **報告義務と情報共有**：誰が誰に報告し、説明責任を負うか。情報がどこまで共有されるか。

### 現在の構造を点検する問い

事業単位は戦略目標を達成しやすい編成か／適材適所か／意思決定は適切かつ効率的に下されているか／戦略目標に最も貢献した実績が正しく評価・報奨されているか／報告・情報共有はタイミングよく効率的か。
※〈離陸〉局面では既存構造を評価する必要はなく、望ましい構造を新たに構想する。

### トレードオフ表（この章の核心の一つ）

**完璧な組織は存在しない。優良企業でもどこかで妥協する。だから「どの歪みを引き受けるか」を選ぶのが組織設計**。4要素それぞれに、相反するメリット・デメリットがある。

| 構造要素 | 一方の選択 | その代償（裏側） |
| --- | --- | --- |
| **知識・能力（チーム編成）** | 同質の人材で固める → 専門知識が蓄積しやすい | 視野が狭くなり孤立しやすい |
| | 多様な人材で混ぜる → 視野が広く孤立しにくい | 専門性の高い知識は育ちにくい |
| **意思決定** | 集中（上が決める）→ 短時間で効率よく決まる | 現場の情報・知恵を生かせず、一人に負担が集中、誤判断しやすい |
| | 分散（現場が決める）→ 現場の情報を生かせる | 全体への影響を考えない勝手な決定が出やすい |
| **報奨制度** | 個人評価重視 → 個人の貢献に報いる | チームワーク軽視だと個人プレーに走る（→ハナの会社の顧客奪い合い） |
| | チーム評価重視 → 協働を促す | 個人の貢献が埋もれ、意欲を失わせることがある |
| **報告・説明責任** | 単純な上下関係 → 分かりやすい | 縦割り化し、情報共有が進まない |
| | マトリクス型 → 情報共有が広い、縦割りを防ぐ | 説明責任が曖昧になり、合意形成に時間がかかる |

**読み方**：表の左右はどちらも一長一短で、「正解」はない。自分の戦略がどちらの強みを必要としているかで選び、選んだ側の代償（裏側）を意識して手当てする。たとえば「協働が戦略の肝」ならチーム評価寄りにするが、その代償（個人の埋没・意欲低下）を別途フォローする、という具合。ハナの会社は「協働が必要な戦略」なのに「個人報酬」を選んでいた＝戦略と構造のトレードオフ選択を誤っていた事例。

## 第三のS：システム（業務プロセス）

情報・材料・知識は、システム（プロセスの体系）を通じて製品・サービス・アイデアに変換される。構造とシステムは人体の比喩で理解する＝構造（骨格・筋肉）とシステム（循環器・消化器）はどちらも健全で、互いに支え合う必要がある。

**手順**：プロセス・マップを作る（各人が担当を書き出し、チームで線でつなぐ。これ自体が組織学習の機会）→ 戦略実行に最も大切な**コア・プロセス**を特定 → 改善。
**コア・プロセスの4評価軸**：生産性／時期（タイミング）／信頼性／品質。
**禁止事項**：一度に2つ以上のプロセスを変えない（人は大幅な変更を受け入れられない）／むやみに自動化しない（プロセス問題の多くは意思疎通の不備・手順の不徹底・誤解。根本解決の方が自動化よりメリットが大きい）。

---

## 第四のS：スキル（能力開発）

部下にコア・プロセスを確実にこなす能力があるか。なければ戦略目標は実現せず、アーキテクチャ全体が機能しない。
**4分類**：個人の能力／関係構築能力（個人の知識を統合して組織で達成する力）／技術的能力（DB・研究開発力等）／メタ知識（知識がどこにあるかの知識）。
**手順**：戦略とコア・プロセスから理想の能力構成を描く → 現状との乖離を把握 → **眠った資源の発掘**（平均以上の実績を出す部下・チームを探し「なぜ有能か」を分析し横展開、資金不足で眠るアイデアを掘り起こす）。

## 一つのC：文化

文化は4Sすべてに深い影響を与える。目に見えない規範・価値観から成り、長い時間で根を下ろすため存在すら意識されないことが多い。変革が必要なときですら現状維持に働くやっかいな代物。放っておくと文化は4Sを支えるどころか足を引っ張る。

**観察ポイント**：表面（やりとり・態度・服装）だけでなく暗黙の規範＝「見えない決まり」を見つける。特に **影の権力**（一目置かれる影の実力者は誰か）と **価値観**（何が価値の創出とされているか：利益か顧客満足かイノベーションか）。
**文化にメスを入れる5ヒント**（どれも4Sとの調和が前提）：①実績評価基準とインセンティブを変える ②パイロット・プロジェクト ③社外から人材を登用 ④組織学習を奨励 ⑤集団思考を打破。90日でできるのは理解と「ごく一部」の変更まで。

## やってはいけない組織いじり（落とし穴）

- **深刻な問題の最中に組織再編**：嵐の中で大工仕事をする愚行。再編が真の解決策か確かめる。
- **構造の複雑化**：「創造的緊張」は魅力的に聞こえるが縄張り争いの官僚主義に陥る。責任分担は一本の線、組織図は単純に。
- **IT頼みの自動化**：既存プロセスの高速化だけでは解決せず悪化も。先に手作業での合理化。
- **改革のための改革**：塀を壊す前に、なぜその塀が立てられたか考える（行動強迫の組織版）。
- **組織の順応力の過信**：野心的な戦略は口では簡単。時間が許すなら緊急度の高い所から少しずつ、戦略→構造→プロセス→スキル→文化へ徐々に広げる。

## 事例：ハナ・ジャフィー

投信会社の人事担当副社長にヘッドハント。社長の依頼は「不穏分子のクビ切り」だったが、ハナは診断の結果、真因は人でなく構造（報酬制度＝個人インセンティブの設計）が顧客の奪い合いを生んでいると見抜く。組織を変える権限はないので、社長を説得する側に回り、他社事例のデータを集めて粘り強く進言。最終的に製品別→顧客別の編成替え＋統括ポスト新設＋社外からの登用で、1年後に顧客満足度向上・利益15%増。「人を替えれば直る」という思い込みを構造診断で覆した事例。

2. 顧客・資金・能力・重点分野のどこに問題があるか。

4. 現構造の長所短所は。手直しは必要か。

7. 文化のうち戦略にプラス・マイナスの要素はどれか。
