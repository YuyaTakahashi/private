# 第六章　組織をデザインする ── まとめ（機構中心版）

> マイケル・ワトキンズ『最初の90日』／疑問・感想は `読書ノート.md` に蓄積する。
> 構成方針：道具（機構）を主役に再構成。

## この章の主張（ひとことで）

地位が上がるほど、リーダーの仕事は「自分が頑張る」ことから「**能力を発揮しやすい組織を設計する**」ことに移る。どれほどカリスマ的なリーダーでも、屋台骨が歪んだ組織では成果は出ない。組織を〈四つのSと一つのC〉に分解して診断し、要素間の不協和音を見つけて直す。90日でできるのは粗い診断と最悪の部分への着手まででよい。

**権限がなくても使える**：ハナのように組織を変える権限がなくても、「業績低迷の原因は組織体制にある」と上司を説得する道具になる（この章の事例自体が説得の実演）。

## 道具箱（この章の機構）

### 道具1：〈四つのSと一つのC〉診断フレーム

- **目的**：組織を5要素に分解し、各要素を単独で採点する（「戦略はいいか」「人材はいるか」と一個ずつ丸バツ）のではなく、**要素どうしが同じ方向を向いて噛み合っているか（整合）**を診る。各要素が単独で立派でも、つなぎ目がずれていれば組織は回らない。
  - 例：ハナの会社は人材も優秀、報酬制度（個人の成果に報いる）もそれ自体は真っ当＝単独採点なら合格。だが戦略は「部門が協力して顧客に一体的サービスを」なのに、報酬は「個人成績で報いる＝協力する動機がない」方向を向き、戦略と制度が逆向きで噛み合っていなかった。結果、優秀な人材が顧客を奪い合った。
  - 比喩：高級ギアと高級チェーンを別々に買っても規格が合わなければ走らない。部品の良し悪しでなく、部品どうしが噛み合うかが問題。
  - 使い方：「戦略はいいか？」と単独で問わず、「戦略と制度は同じ方向か？」「戦略とスキルは噛み合うか？」と必ず2要素をペアで問う（だから下記の不協和音パターンは全て「○×○」のペアで書かれている）。
- **5要素**：**戦略**（目標達成のグランドデザイン）／**組織構造**（人材配置と業務分担）／**システム**（業務プロセスの集合体）／**スキル**（個人やチームの能力）／**文化**（価値観・規範・信念。4Sすべてを包む）。
- **原理**：どれか一つでも戦略から逸脱したら目標達成はおぼつかない。戦略を変えれば構造・システム・スキルも変わる（相互依存）。
- **不協和音の典型パターン**：戦略×スキル（新商品をどんどん出す戦略なのに実験を効率化する技術がない）／システム×戦略（新規顧客セグメント戦略なのに顧客情報を蓄積・分析するシステムがない）／構造×システム（製品別チーム編成なのに他チームの専門知識を使う仕組みがない）。

### 道具2：組織設計の手順（順番を間違えない）

1. **戦略を立てる**（全社目標・自分の業績目標に照らした自部署の位置づけから）
   - 「自部署の位置づけ」＝会社全体の目標の中で、自部署がどんな役割を割り当てられているか。自部署だけ見て戦略を作ると全社とズレる。まず一段上（全社目標）を見て、その中で自部署の役割を確かめてから自部署の戦略を立てる、という順番の指示。
   - 例：全社が「利益重視・既存顧客を固める」なら、営業部の役割は「解約防止・単価向上」、開発部の役割は「新機能より安定性・改善」。同じ会社でも全体目標の中での役割は部署ごとに違う。これを確かめず「開発部だから新機能を作る」と決めると、利益重視局面では空回りする。
   - 「業績目標に照らして」＝その自部署の役割が、第四章で立てた自分の業績目標（測れる目標）とつながっているか確認する意味。全社目標→自部署の役割→自分の業績目標が一直線につながっているか点検してから戦略を立てる。
   - 第五章との接続：自部署の位置づけ・業績目標は一人で決めず、上司との対話（現状認識・期待のすり合わせ）で確かめる。第六章の組織設計は第五章の上司対話を前提にしている。
2. **構造・システム・スキルで支えられるか吟味する**
3. **新戦略の導入時期と方法を決める**（無理のない期限）
4. **構造・システム・スキルは同時に変える**（三者は密接に結びつき、一つだけ取り出せない）
5. **学習し続ける**
- **原理**：戦略を決めずに構造をいじるのは非効率。能力開発も目標・戦略・構造が定まってから。

> **道具3と道具4の違い**：3＝戦略を「作る/組み立てる」ための構成材料（向いている問い＝「何を決めるべきか」）。4＝すでにある戦略を「評価する/検査する」ためのレンズ（向いている問い＝「この戦略は良いか、直すべきか」）。順番は3が先・4が後（新任は前任者の戦略を引き継ぐので、まず3で中身を分解把握→次に4で品質検査→修正の要否を判定）。料理の比喩＝3は材料表、4は試食の評価シート。※本書は両者をきれいに分離しておらず記述が一部重複する（「裏付けをとる」は3の資金と4の妥当性で同内容）。

### 道具3：戦略の中身を点検する〈4つのC〉（戦略を組み立てる材料）

- **顧客**：大切にする顧客は誰か。撤退すべきセグメント、参入すべきセグメントは。
- **資金**：投資が有望な分野は。資源は確保されているか。
- **能力**：何が得意で何が不得意か。これから要る能力は自前で育成できるか。
- **重点分野**：資源をいつどこに投入するか。継続するもの、撤退するものは。

### 道具4：戦略評価の3レンズ（できた戦略を検査する）

- **整合性**：戦略の構成要素（市場・製品・技術・実行計画・目標）が矛盾なく調和しているか。市場分析と事業目標の食い違い、開発予算と投資計画のずれ等をチェック。
- **妥当性**：今後2〜3年のニーズと全社戦略に照らして適切か。手法＝①裏付けをとる（上司は本気で信じているか、資源・利益目標・投資資金はあるか）②SWOT分析③**立案プロセスの検証**（短時間で慌ただしく作られた→波及効果が未検討の恐れ／会議を重ねて作られた→最大公約数的妥協の恐れ）。
- **実行状況**：**部下の説明よりも行動に注目する**。評価基準は戦略とリンクし日々の意思決定に生きているか／管理職の行動は戦略と矛盾していないか／必要なチームワーク・部門横断は実際に行われているか／必要なトレーニングは用意されているか。

### 道具5：戦略変更の作法（針路修正向き）

- 「うまくやっている」と信じる部下に変更を説得するのは最難関の仕事。**質問で揺さぶる**：「この戦略目標が実現したら想定外の副作用はないか」「市場拡大が本当に当社の望みか」「もう少し現実的な目標を別に設定しては」。
- 戦略自体は妥当で進みが鈍いだけなら、**当面は微調整で様子見**（収益目標を少し上げる、投資を前倒す）。実態を把握し援護射撃を得てから大幅変更に手をつける。

### 道具6：組織構造の4要素とトレードオフ表

- **4要素**：事業単位（職能別/製品別/地域別）／意思決定権（誰に決定権、どんなプロセス）／実績評価・報酬制度／報告義務と情報共有。
- **点検**：事業単位は戦略目標を達成しやすい編成か。適材適所か。意思決定は適切かつ効率的か。戦略への貢献が正しく評価・報奨されているか。情報はタイミングよく共有されているか。
- **トレードオフの理解（完璧な組織は無理、バランスを選ぶ）**：
  - 知識・能力：同質チーム＝専門知識が蓄積するが視野が狭くなる ⇔ 多様チーム＝その逆。
  - 意思決定：集中＝速いが現場の知恵を生かせず一人に負担 ⇔ 現場一任＝全体への影響を顧みない勝手な決定のリスク。
  - 報奨制度：個人軽視＝意欲を失わせる ⇔ チームワーク軽視＝個人プレーに走る（ハナの会社＝顧客の奪い合いはこれ）。
  - 報告関係：単純な上下＝分かりやすいが縦割り化 ⇔ マトリクス＝縦割りは防げるが説明責任が曖昧になり合意形成が遅い。
- **例外**：〈離陸〉では既存構造の評価は不要。代わりに望ましい構造の構想を練る。

### 道具7：プロセス・マップとコア・プロセス改善

- **手順**：プロセス・マップを作る（各人が担当プロセスを書き出し、チームで線でつなぐ）→ 誰が何をしているかを全員が理解＝**組織学習の機会**になり、ボトルネックが見える → 戦略実行に最も大切なプロセス＝**コア・プロセス**を特定 → 改善。
- **コア・プロセスの4評価軸**：生産性／時期（タイミング）／信頼性／品質。
- **禁止事項**：一度に2つ以上のプロセスを変えない（人は大幅な変更を受け入れられない）／むやみに自動化しない（プロセス問題の多くは意思疎通の不備・手順の不徹底・誤解。根本解決の方が自動化よりメリットが大きい）。
- **構造とのすり合わせ**：人体の比喩＝構造（骨格・筋肉）とシステム（循環器・消化器）はどちらも健全で支え合う必要がある。

### 道具8：スキルの4分類と乖離分析

- **4分類**：個人の能力／関係構築能力（個人の知識を統合して組織で達成する力）／技術的能力（DB・研究開発力等）／メタ知識（知識がどこにあるかの知識）。
- **手順**：戦略とコア・プロセスから理想の能力構成を描く → 現状との乖離を把握（すぐ補えるもの／時間がかかるもの）→ **眠った資源の発掘**：平均以上の実績を出す部下・チームを探し「なぜ有能か」（特別な経験・技術・サポート？）を分析し、他へ横展開できないか。資金不足で眠っているアイデアはないか。

### 道具9：文化にメスを入れる5ヒント

- 90日でできるのは文化の理解と「ごく一部」の変更まで。どの方法も4Sとの調和が前提。
  1. **実績評価基準とインセンティブを変える**（チーム目標ならチーム報奨へ比重移動）
  2. **パイロット・プロジェクト**（新しい行動パターンになじむ機会を作る）
  3. **社外から人材を登用**（マンネリ打破。専門性＋調整役にふさわしい対話力）
  4. **組織学習を奨励**（発想を転換させる学習、優良企業のベンチマーク）
  5. **集団思考を打破**（会社を離れた自由な場でのブレインストーミング等）
- **文化の観察ポイント**：表面（やりとり・態度・服装）だけでなく暗黙の規範＝「見えない決まり」を見つける。特に注目すべき2点＝**影の権力**（一目置かれる影の実力者は誰か）と**価値観**（何が価値の創出とされているか：利益か顧客満足かイノベーションか）。

### 道具10：よくある過ちの判定リスト（やってはいけない組織いじり）

- **深刻な問題の最中に組織再編**：嵐の中で大工仕事をする愚行。組織再編が真の解決策か確かめる。
- **構造の複雑化**：「創造的緊張」は魅力的に聞こえるが縄張り争いの官僚主義に陥る。責任分担は一本の線で、組織図は単純に。
- **IT頼みの自動化**：既存プロセスの高速化だけでは解決しないどころか悪化。先に手作業での合理化。
- **改革のための改革**：塀を壊す前に、なぜその塀が立てられたのか考える（行動強迫の組織版）。
- **組織の順応力の過信**：野心的な戦略を口で言うのは簡単。時間が許すなら少しずつ、緊急度の高い所から。戦略変更は控えめに始めて構造→プロセス→スキル→文化へ徐々に広げる。

## 心構え系の記述（流し読みでよい部分）

- 「リーダーはアーキテクトたれ」：ただし管理職で組織設計のトレーニングを受けた人はほとんどいない。「なぜ馬鹿な上司はこの非効率を放置するのか」と文句を言っていた人が、いつの間にか同じ側に回る。だから意識的に学ぶ必要がある。
- 航海のメタファー：目的地（使命・目標）→航路（戦略）→船（構造）→装備（システム）→乗組員の訓練（スキル）。海図にない珊瑚礁への見張りを怠らない。

## 事例：ハナ・ジャフィー（道具の実演として読む）

投信会社の人事担当副社長にヘッドハント。社長の依頼は「不穏分子のクビ切り」だったが、ハナは診断の結果、真因は人でなく構造にあると見抜く（道具1：報酬制度＝個人インセンティブの設計ミスが顧客の奪い合いを生んでいた＝道具6のトレードオフ）。権限はないので社長を説得する側に回り、データ（他社事例）を集めて粘り強く進言（道具5の作法に近い）。最終的に製品別→顧客別の編成替え＋統括ポスト新設＋社外からの登用（道具9のヒント3）で、1年後に顧客満足度向上・利益15%増。「人を替えれば直る」という上司の思い込みを、構造診断で覆した事例。

## 章末チェックリスト（要約）

1. 4S+1Cは調和しているか。組織をさらに理解するには。
2. 顧客・資金・能力・重点分野のどこに問題があるか。
3. 戦略は目標と一致しているか。修正は必要か。
4. 現構造の長所短所は。手直しは必要か。
5. コア・プロセスはどれで、機能しているか。どれを優先改善するか。
6. 理想のスキルと現状の差は。眠っている能力・人材はないか。
7. 文化のうち戦略にプラスの要素・マイナスの要素はどれか。
