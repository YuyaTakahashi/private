# UX collective勉強会0311 まとめ（memo2）

- 記事タイトル: "Enhance UX research with deconstruction"
- URL: https://uxdesign.cc/enhance-ux-research-with-deconstruction-d4d418dd8db9
- 概要:
  - 本記事は、フランスの哲学者ジャック・デリダによる「脱構築（deconstruction）」の考え方をUXリサーチに応用する意義を解説している。
  - デリダは、言語や構造に潜む二項対立（例：シンプル／複雑、直感的／非直感的、主要／二次的）を批判的に問い直し、優劣や前提を揺さぶることで新たな意味や視点を生み出す手法を提唱した。
  - UXリサーチでも「ユーザーはシンプルなUIを好む」「スワイプは直感的」などの“常識”やバイナリ（対立構造）を鵜呑みにせず、なぜその前提が生まれたのか、逆転させたらどうなるか、背景にどんな文化的・組織的要因があるかを問い直すことが重要だと説く。
  - 具体的には「バイナリの特定→優劣の逆転→前提や文脈の可視化→両者を共存させる設計」という4ステップを紹介し、実例として「ライブチャットvsメールサポート」などの分析を通じて、単純な二項対立に回収されない多様な解決策の可能性を示している。
  - 脱構築的な視点を持つことで、リサーチ結果やインサイトを“絶対的な真実”として扱うのではなく、常に問い直し続ける姿勢が、より柔軟で人間的なUXデザインにつながるとまとめている。
