# 記事サマリー：Enhance UX research with deconstruction

**著者:** Michael Buckley

## 1. 記事の核心：UXリサーチにおける「脱構築」とは
フランスの哲学者ジャック・デリダが提唱した「脱構築（Deconstruction）」をUXリサーチに応用する手法についての解説です。

リサーチで導き出されたインサイトを「固定された真実」として鵜呑みにすることには、**「単純な帰結により重要な落とし穴を見逃す」「浅くて抽象的な自明の結論しか出せない」**というリスクが伴います。これらを解体（dismantle）し、前提を問い直すことで、イノベーションの源泉である「混沌とした部分（Messiness）」を捉え、より深く人間的なデザインの可能性を広げることを目的としています。

## 2. 二項対立（バイナリ）の落とし穴
デザインの現場では、一方が優れているとされる「対の概念（二項対立）」が頻繁に現れます。脱構築はこれらを批判的に検証します。

*   **「ビジネスかUXか」の両立と分解**:
    「ビジネス（安全性）をとるとUX（手軽さ）を損なう」という二項対立を分解します。「誰が、いつ、どんな状況で？」と問い直すと、実は全ての振込に厳重な認証は不要で、「普段と異なるIPや高額振込など、リスクが高い時だけ認証する」といった、両立の道が見えてきます。
*   **解決すべきことの見極め**:
    「なぜ？ 誰にとって？ いつ？」と問い続けることで、単なる簡略化（シンプル化）では見落としていた、**真に解決すべきポイント**を特定できるようになります。
*   **「直感的」の罠**: 
    「スワイプはボタンより直感的」という結果に対し、「直感的」とは単に「以前に見たことがある（筋肉の記憶）」に過ぎないのではないか？と疑います。ある人にとっての「自然」が、その文化や習慣を知らない人を排除していないかを検討します。
*   **「ペルソナ」の階層構成**: 
    「主要ユーザー（Primary）」という定義は、「二次的ユーザー（Secondary）」がいるからこそ成立します。この優先順位を逆転させ、境界にいるユーザーを基準に考えると、プロダクトの言語や機能が全く異なる視点で見えてきます。

## 3. 実践メソッド：インサイトを「尋問」に変える
リサーチ結果を「答え」ではなく「対話の始まり」にするための4ステップです。

1.  **対立構造の特定**: 「シンプル/複雑」「主要/二次的」「ライブチャット/メール」などの対を書き出す。
2.  **階層の逆転**: 優先順位をあえて逆にし、もし「劣っているとされる側」を優先したらどうなるか？を問う。
3.  **前提の可視化**: なぜ一方が優先されているのか（文化的背景、ビジネスの都合、個人の好みなど）を暴く。
4.  **両者を共存させる**: どちらか一方に決めるのではなく、文脈に応じて双方が有効になるような設計を探る。

## 4. なぜこれが重要なのか
リサーチ文化は「確実性（石に刻まれた真実）」を好みますが、デザイナーにとっての真の機会は、その石を刻む前の「混沌とした部分」にあります。

脱構築を適用することで、リサーチを福音（絶対的な真理）として扱うのをやめ、ユーザー・プロダクト・それらが存在する矛盾だらけの世界との**「継続的な対話」**に変えることができます。これにより、デザインの決定はより思慮深く、適応性のある、そしてより人間的なものになります。
