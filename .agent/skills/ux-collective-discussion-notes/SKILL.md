# UX Collective Discussion Notes

## 概要

各回のフォルダにある素材から `discussion_notes_YYYYMMDD.md` を作成する。

## 素材の収集

対象回のフォルダ（例: `読書会・勉強会/UX collective勉強会/0318/`）から読み込む：

1. `info.md` — 記事URLとメモ画像のファイル名を確認する
2. `transcript.md` — 音声認識による文字起こし
3. `memo*.jpg` — ホワイトボードの板書写真（全枚）

## 記事内容の取得

`info.md` のURLから各記事の内容を取得し、詳しくまとめる。
- WebFetchで取得できない場合はWebSearchで補完する
- メモ画像の板書も参照して補足する

## 参加者の特定

固定参加者：**高橋祐哉 / 鈴木ゆうや / 大本あかね**（＋その回のゲスト）

transcript の話者IDを以下のルールで推定する：
- `高橋祐哉 祐哉` → 高橋祐哉（確定）
- 他の参加者名はtranscript内の呼びかけ（「〇〇さんいかがですか」「〇〇さんが言ったように」など）から特定する
- **参加者数より話者IDが多い場合**は、音声認識による同一人物の分割を疑う（その旨注記する）
- 特定しきれない場合は「〇〇（推定）」と注釈を入れる

## 出力フォーマット

```
# 勉強会メモ YYYY/MM/DD

**参加者：** 高橋祐哉 / （その他）

> transcript注記：（話者IDの分割など、必要な場合のみ記載）

---

## 記事N：〇〇

**URL：** ...

### 記事の内容詳細

（記事の主要な主張・フレームワーク・事例・キーワードを詳しく）

### 参加者の発言・気づき

**高橋祐哉（自分）**
- ...

**〇〇さん**
- ...

### 自分のメモ（記事N：記事以外の気づき）

（ホワイトボードから読み取れる、記事内容以外の個人的な気づき・疑問・自プロダクトへの接続）

---
```

## 整理ルール

- **記事ごとに振り分ける**：各参加者の発言を記事1・記事2それぞれのセクションに分けて記載する
- **transcript記録がない記事**：メモ画像から発言を復元し「transcriptに記録なし。memo*.jpgの板書から復元」と注記する
- **板書の読み取り**：記事内容に関するメモと、個人的な気づき・疑問・自プロダクトへの接続メモを分けて整理する

## 出力先

`discussion_notes_YYYYMMDD.md` を対象回のフォルダに保存する。
