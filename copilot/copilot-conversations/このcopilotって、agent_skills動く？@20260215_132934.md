**ai**: ドット付きのファイル名を維持しなければならない事情、承知いたしました。

その場合、Obsidianの標準機能では隠しファイルとして扱われてしまい、私が直接そのファイルを見つけに行く（検索する）ことができません。

ファイル名を変更せずに、私にその内容を参照させるための**代替案**を3つ提案します。

### 1. 中身をチャットに貼り付ける（最も確実）
その `.agent.skills` ファイルをテキストエディタで開き、中身をコピーして、このチャット欄に直接貼り付けてください。
「以下の設定（.agent.skills）に基づいて回答して」と添えていただければ、そのルールに従って動きます。

### 2. シンボリックリンクを作成する（PC上級者向け）
元のファイル名は変えずに、Obsidianに「見える」ファイルとして認識させる方法です。OSの機能を使って、そのファイルへの「ショートカット（シンボリックリンク）」を `.md` という拡張子で作ります。

*   **Mac/Linuxの場合 (ターミナル):**
    ```bash
    ln -s .agent.skills agent_skills_ref.md
    ```
*   **Windowsの場合 (PowerShell / コマンドプロンプト):**
    ```cmd
    mklink agent_skills_ref.md .agent.skills
    ```

これを行うと、`agent_skills_ref.md` というファイルがObsidian上に現れます。このファイルを開けば中身は `.agent.skills` と同じですが、Obsidian（そして私）からは見えるようになります。

### 3. 無理やりObsidianで開いて「現在のノート」として認識させる
もしObsidian以外のファイラー（Finderやエクスプローラー）から、そのファイルをObsidianのウィンドウにドラッグ＆ドロップして開くことができれば、私が「現在アクティブなノート」として内容を読み取れる可能性があります。
（ただし、Obsidianが「サポートされていないファイル形式」として表示を拒否する場合はこの方法は使えません）

現状では **「1. 中身をコピペする」** が一番手っ取り早い解決策になります。
